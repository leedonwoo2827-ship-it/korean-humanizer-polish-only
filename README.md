# 한국어 AI 윤문 에이전트 (korean-humanizer · Codex · Claude OAuth)

ChatGPT·Claude·Gemini의 도움을 받아 쓴 원고에서 **'AI 티'가 나는 곳을 찾아 표시하고(진단),
고칠 구절마다 수정 문구와 수정확률을 제안해(윤문) 사람이 체크한 것만 정오표로 내 주는** 도구입니다.
원고는 이 정오표를 보고 저자에게 확인한 뒤 사람이 직접 고칩니다
([JEV 개정 에이전트](https://github.com/leedonwoo2827-ship-it/jev-revision-agent)와 같은 방식).

한국어 AI 글의 티는 대부분 **영어 번역투**와, 격식을 가장한 **상투어**에서 나옵니다.
"~을 통해", "~에 있어서", "중요한 의미를 가진다", "되어진다", "시사하는 바가 크다", 줄표(—), 연결어미 뒤 쉼표,
"결론적으로", "다채로운 향연", "앞으로의 행보가 기대된다"…
이 도구는 그런 흔적을 **심각도(S1·S2·S3)** 로 나눠 짚고, 짚은 곳만 수술하듯 고칩니다.
맞춤법 교정과도, 유행어를 입히는 일과도 다릅니다. **문체·리듬·표현**만 사람답게 되돌립니다.

[TS 속독 에이전트](https://github.com/leedonwoo2827-ship-it/galley-errata-agent)와 같은 콘솔·로그인 방식입니다.
이미 TS 속독을 쓰는 PC라면 Codex 로그인이 그대로 됩니다.
AI 엔진은 **Codex(ChatGPT 구독)** 와 **Claude(Claude 구독)** 중 고를 수 있고, 둘 다 API 키 없이 계정 로그인으로 씁니다.

> **이 도구가 하는 일은 '윤문'까지입니다.**
> 이미 쓴 문장을 다듬을 뿐, 자료를 찾거나 사실을 확인하거나 내용을 보태거나 분량을 채우지는 않습니다.
> 그 일은 여전히 글쓴이의 몫입니다. 원고의 무게는 그대로 두고, 그 위에 앉은 AI의 먼지만 털어 냅니다.

## ■ 준비 (처음 한 번)

1. **`setup.bat` 더블클릭**
   - Python · Node.js가 없으면 설치 페이지가 열립니다. 설치한 뒤 `setup.bat`을 다시 더블클릭하세요.
     (Python 설치 첫 화면 아래의 **"Add python.exe to PATH"** 를 꼭 체크)
   - 브라우저가 열리면 **ChatGPT 계정으로 로그인** → "로그인 완료"가 뜨면 끝입니다.
   - Claude도 쓰려면 [Claude Code](https://docs.claude.com/ko/docs/claude-code)를 설치하고(`npm install -g @anthropic-ai/claude-code`)
     콘솔 왼쪽 아래 **Claude 메뉴의 [로그인]** 을 누릅니다. 이미 Claude Code를 쓰는 PC라면 그대로 됩니다.
2. **`run.bat` 더블클릭** → 브라우저에 콘솔이 열립니다.
   검은 창은 끄지 말고 최소화해 두세요. 끄면 콘솔도 멈춥니다.

> **주소는 `http://localhost:8767/` 입니다.**
> 브라우저가 저절로 안 열리면 주소창에 직접 입력하세요.
> `127.0.0.1:8767` 로는 안 되는 경우가 있으니 꼭 **localhost** 로 입력하세요.

## ■ 사용법

1. **「새 글 넣기」** — 워드(.docx)·텍스트(.txt·.md)·PDF를 끌어다 놓거나, 글을 붙여넣습니다.
   한글(.hwp)은 한글에서 *다른 이름으로 저장 → Word 문서(.docx)* 로 바꿔서 올려 주세요.
2. **「글 설정」** — 장르(단행본 원고·논문·칼럼·보도자료·블로그…)를 고릅니다. 필요하면
   - **목표 글자수**: "1000자로" 같은 분량 맞춤 (기본 ±5%, '정확히'는 ±2%. 공백 포함/제외 선택)
   - **문체 샘플**: 저자가 직접 쓴 글 한두 문단 → 그 말투로 다듬습니다.
3. **「① AI 흔적 진단만」** — 고치지 않고 흔적만 색칠해 보여 줍니다.
   **「② 윤문하기」** — 진단 → 윤문 → 감사 → 등급까지 한 번에 합니다. 긴 글은 대시보드에서 절별 · 단계별로 돌리는 게 좋습니다.
4. **「수정 후보 · 체크」** — 고칠 구절마다 `기존 문구 → 수정 문구` · **수정확률** · 분류 · 이유 · 쪽 · 문단이 나옵니다.
   - **수정확률 60% 이상은 처음부터 체크**되어 있습니다. 확률·절로 걸러 보고, 체크를 켜고 끕니다.
   - 「원문 보기」로 그 구절이 문단 어디에 있는지 확인하고, 수정 문구를 고치거나 메모를 남깁니다.
   - 쪽은 PDF로 넣은 원고만 나옵니다(PDF 쪽 기준). 워드·붙여넣기는 문단 번호로 찾습니다.
5. **「반영 → 정오표 만들기」** → `05_반영본/` 에 **책 전체 정오표가 한 번에** 나옵니다(절 · 쪽 순).

   | 파일 | 쓰는 곳 |
   |---|---|
   | `<제목>_정오표.xlsx` | 「정오표」(체크한 것) · 「전체 후보」(반영 O 칸 · 수정 문구 · 메모를 고칠 수 있음) · 요약 · 남은 흔적 · AI 흔적 |
   | `<제목>_정오표_검토.pdf` | 회의용 종이. 후보 전부에 ☐/☑ 체크칸과 메모칸. 인쇄해서 표시하거나 스캔해 돌려줄 때 |
   | `<제목>_정오표_검토.html` | 브라우저에서 체크박스 · 수정 문구 · 메모를 고치고 **[체크 결과 저장]** (인쇄하면 PDF와 같은 종이) |
   | `<제목>_정오표_게시판.html` | 체크한 것만 — 회사 게시판에 올리는 정오표 |
   | `<제목>_정오표.txt` | `[절 · p.쪽] '기존' → '수정'` 한 줄씩 |
   | `<제목>_윤문본.docx · .txt` | 체크한 것을 적용해 본 참고용 원고 |

6. **사람끼리 회의한 뒤 결과 되돌리기** — 검토 HTML에서 저장한 `.json`, 또는 「전체 후보」 시트를 고친 `.xlsx` 를
   글 화면의 **「체크본 가져오기」** 로 올리면 체크 · 수정 문구 · 메모가 그대로 들어갑니다(ID로 맞춤). 다시 「반영」을 누르면 파일이 새로 나옵니다.
   종이에 표시한 스캔본은 ID 칸을 보고 직접 체크하면 됩니다.

## ■ 대시보드 — 단계를 나눠 시간대별로

왼쪽 **「대시보드」** 에서 글이나 절을 체크하고 단계 버튼을 누르면, 고른 부분에만 그 단계를 합니다.
Codex(ChatGPT) 사용 한도는 **5시간마다 쓸 수 있는 양**이 정해져 있고 다른 에이전트와 함께 씁니다.
그래서 단계를 나눠 두었습니다. 오전에 진단, 오후에 윤문처럼 **시간대를 갈라 돌릴 수** 있습니다.

| 버튼 | 하는 일 | Codex 호출 |
|---|---|---|
| **1 진단** | 구간마다 AI 흔적을 찾아 표시합니다 | 구간마다 1회 |
| **2 윤문** | 진단된 곳에 수정 후보(기존 → 수정 · 수정확률 · 이유)를 냅니다. 진단이 안 된 부분은 건너뜁니다 | 구간마다 1회 |
| **3 감사** | 수정 후보를 모두 반영했을 때 흔적이 남는지 다시 봅니다. 윤문이 안 된 부분은 건너뜁니다 | 바뀐 구간마다 1회 |
| **4 반영** | 정오표(엑셀 · 검토 PDF/HTML · 게시판 HTML · txt)를 **책 전체 한 번에**, 절 · 쪽 순으로 만듭니다 | 없음 |
| **▶ 1→3 · ▶ 1→4** | 앞 단계부터 차례로 끝까지 합니다 | 위를 합친 것 |

- **긴 글(2만 자 넘음)은 절·장으로 나눠 보여 줍니다.** "1절 … 2절 …", "제1장", "PART 1" 같은 제목 줄로 나누고(목차 줄은 건너뜀),
  제목이 없으면 약 3만 자씩 나눕니다. 결과는 한 글 안에 쌓이고, 이미 한 절의 윤문·체크는 다른 절을 돌려도 그대로 남습니다.
  **보통은 1절을 ▶ 1→4로 끝내고, 정오표를 저자·디자인실과 확인한 뒤 다음 절로 넘어가는 식**으로 씁니다.
- 표의 칸에 적힌 **「N구간」은 남은 Codex 호출 수**입니다. 마우스를 올리면 어림 시간이 나옵니다. 끝난 칸은 ✓ 입니다.
- 이미 된 곳은 건너뛰고 실패한 구간만 다시 합니다. 한 편이 실패해도 다음 편으로 넘어갑니다.
- **사용 한도에 걸리면 기다렸다가 같은 곳부터 이어서** 합니다(기본 최대 8시간, 0이면 바로 멈춤). 기다리는 동안 PC 절전을 막습니다.
  퇴근 전에 걸어 두고 검은 창(run.bat)만 켜 두면 됩니다.
- 언제든 **「■ 멈춤」** 으로 멈출 수 있습니다. 끝난 구간은 기억해 두므로 다시 누르면 이어서 합니다.
- 정오표에 들어가는 것은 글 화면 「수정 후보 · 체크」에서 고른 대로이고, 손대지 않았으면 기본값
  (수정확률 60% 이상 · 원문에서 위치를 찾음 · 숫자·인용을 빠뜨리지 않음)입니다.

### 걸리는 시간 (Codex · 3구간 동시 · 6,000자 구간 기준)

글자수는 공백 포함입니다. **아직 실측 전의 어림이라 써 보면서 고칠 예정입니다.**
원고의 AI 티가 적으면 윤문·감사를 건너뛰는 구간이 생겨 더 짧아지고, 철칙을 어겨 다시 쓰는 구간이 많으면 더 길어집니다.

| 글자수 | 구간 | 1 진단 | 2 윤문 | 3 감사 | 4 반영 |
|---|---|---|---|---|---|
| 1만 자 | 2 | 약 1분 | 약 1분 | 약 1분 | 1분 안 |
| 3만 자 | 5 | 약 2분 | 약 3분 | 약 2분 | 1분 안 |
| 6만 자 | 10 | 약 4분 | 약 6분 | 약 4분 | 1분 안 |
| 10만 자 | 17 | 약 6분 | 약 8분 | 약 6분 | 1분 안 |
| 26만 자 | 44 | 약 15분 | 약 20분 | 약 15분 | 1분 안 |

## ■ 엔진과 사용 한도

원고는 약 6,000자씩 나눠 구간마다 한 번 부릅니다. 그래서 호출 수는 대략 **단계마다 글자수 ÷ 6,000회**입니다.
26만 자 단행본 한 권을 끝까지 하면 진단·윤문·감사를 합쳐 130회쯤 됩니다. 호출이 많으면 화면에 미리 경고가 뜹니다.

| 엔진 (대시보드나 왼쪽 아래에서 고름) | 동작 |
|---|---|
| **Codex (ChatGPT)** (기본) | Codex만 씁니다. |
| **자동** | Codex로 하다가 한도에 걸리면 Claude로 넘어갑니다. Claude CLI에 로그인된 PC에서만 넘어가고, 그렇지 않으면 Codex만 씁니다. |
| **Claude** | Claude만 씁니다 (`claude -p`, 기본 모델 sonnet). 개발·점검용으로 한 바퀴를 빨리 돌릴 때. |

한도에 걸리면 남은 구간을 부르지 않고 바로 멈추며, 풀리는 시각과 함께 안내합니다. 대시보드 위쪽에 계정과 요금제(예: Codex · plus)가 나옵니다.

## ■ 기본 흐름 (탐지 → 윤문 → 감사 → 등급)

1. **트리아지** — 흔적이 무더기인지, 서식만 문제인지, 산문까지 다시 써야 하는지 먼저 가립니다.
   서식만 문제면 서식만 고치고, 흔적이 거의 없으면 손대지 않습니다.
2. **탐지** — A~K 분류표로 흔적을 구절·분류·심각도로 표시합니다. 줄표·이모지·이중피동처럼
   확실한 것은 AI 없이 규칙으로도 한 번 더 찾습니다.
3. **윤문** — 흔적마다 자연스러운 표현으로 바꾼 *수정 후보*(기존 → 수정 · 수정확률 · 이유)를 냅니다. 의미·사실·고유명사·수치는 그대로 둡니다.
4. **감사** — "이 글이 왜 아직 AI 같은가?"를 다시 묻습니다. 남은 흔적, 장르·격식 유지, 없던 수사가 끼어들지 않았는지,
   숫자·인용이 빠지지 않았는지, 변경률이 넘치지 않았는지 봅니다. 숫자·인용을 빠뜨린 후보는 처음부터 체크하지 않습니다.
5. **등급** — A~D로 매깁니다. C·D면 2차 윤문이나 사람 검토를 권합니다.

### 4대 철칙

| 철칙 | 뜻 |
|---|---|
| 의미 불변 | 사실·주장·수치·고유명사·직접 인용은 한 글자도 바꾸거나 지어내지 않는다 |
| 근거 기반 | 탐지된 흔적에만 손댄다. 멀쩡한 문장은 건드리지 않는다 |
| 장르 유지 | 원고를 에세이·블로그체로 옮기지 않는다. 원문의 격식(한다체/합니다체)을 지킨다 |
| 과윤문 금지 | 변경률 **30% 넘으면 경고, 50% 넘으면 그 문단은 원문 유지가 기본** |

멀쩡한 사람 글을 평균값으로 깎아 내는 것이 가장 흔한 실패입니다. 그래서 의심스러우면 지우기보다 남깁니다.

| I 형식명사 | ~인 것이다, ~해야 한다, 예고 멘트 | S1~S2 |
| J 시각 장식 | 볼드 남발, 불릿+굵은 머리말, 줄표(—) | S1~S2 |
| K 챗봇 잔재 | 좋은 질문이에요!, 도움이 되었으면 좋겠습니다 (문단째 삭제) | S1 |

- **S1 결정적** — 한 번만 나와도 AI 확신. 무조건 고칩니다.
- **S2 강함** — 한두 번은 괜찮고, 세 번 넘게 반복되면 고칩니다.
- **S3 약함** — 그 자체로는 신호가 아닙니다. 다른 흔적과 겹칠 때만 봅니다.

전체 표(60개 가까운 세부 패턴)는 [`khum/references/ai-tell-taxonomy.md`](khum/references/ai-tell-taxonomy.md)에 있습니다.

### 이런 건 AI 흔적으로 보지 않습니다

반듯한 맞춤법, 격식체·한자어, 접속어 한두 개, 줄표 하나, 개조식 목록 자체, 편지투 인사말.
멀쩡한 사람도 위 패턴 몇 개는 칩니다. 줄표 하나는 아무 의미가 없지만,
줄표 + 3의 법칙 + "다채로운 향연" + "전망" 단락이 한 글에 다 있으면 그건 자백입니다.

그리고 **지어내기 힘든 구체적 디테일, 해소되지 않은 복잡한 심경, 들쭉날쭉한 문장 길이, 진짜 곁말**은
사람이 쓴 글의 신호이므로 지킵니다.

## ■ 참고

- 문단을 합치거나 나누지 않습니다. 원고의 문단 구조는 그대로 남습니다.
- 한 번 돌린 구간은 기억해 두므로, 같은 버튼을 다시 눌러도 빠르고 실패한 구간만 다시 합니다.
- 진행 중에 브라우저를 닫아도 작업은 계속됩니다. 다시 `http://localhost:8767/` 를 열면 됩니다.
- **「Codex 로그인 만료」** 가 뜨면 왼쪽 아래 Codex 메뉴의 [로그인] 또는 `codex-다시로그인.bat` 을 더블클릭하세요.
  **「Claude 로그인 만료」** 면 Claude 메뉴의 [로그인] 또는 명령창에서 `claude auth login`.
  (Claude 메뉴의 [로그아웃]은 이 PC의 Claude Code 로그인도 같이 해제합니다.)
- 다 쓴 글은 **「보관」** 하면 `backup/` 폴더로 옮겨집니다 (지우지 않음). 「새 글 넣기」 화면에서 다시 꺼낼 수 있습니다.
- 원고와 결과물은 이 PC의 `workspace/` 폴더에만 남습니다. 윤문할 때는 원고 내용이 고른 엔진(ChatGPT/Codex 또는 Claude)으로 보내집니다.
